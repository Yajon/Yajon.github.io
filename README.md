### 环境准备

- 安装 [Node.js](https://nodejs.org/en)
- 安装 [pnpm](https://pnpm.io/installation) 或 安装 [Yarn](https://classic.yarnpkg.com/en/docs/install)

### 操作步骤

- 安装依赖

```sh
pnpm install
或
yarn install
```

- 启动 Dev Server

```sh
pnpm run dev
或
yarn dev
```

- 在浏览器访问 http://localhost:3000

- 构建打包

```sh
yarn build
```

- 运行构建预览项目

```sh
yarn preview
```
